# WatchFaces/

Watch face packages (`.hwt`, made with Huawei Theme Studio). After `./generate.sh`, Xcode bundles every `.hwt`
from this folder into the iPhone app, and the app shows an **"Install the … watch face"** button for each of them
under "Watch faces". The file name is the name shown in the app.

Watch faces are not signed for a particular watch, so these files can be shared. Both faces here are made for
466×466 round screens (tested on a HUAWEI WATCH GT 3 SE).
